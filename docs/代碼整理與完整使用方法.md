# LDAPI 代碼整理、配置與使用方法

## 核心環境

- Minecraft 1.12.2
- Paper 1.12.2
- Java 8
- MythicMobs 4.13.0（軟依賴）

## 代碼結構

```text
com.indie.rpg
├─ IndieRPG.java              # 生命週期、管理器初始化、重載
├─ commands/                  # /ld 指令處理
├─ listeners/                 # 玩家、背包、擊殺事件
├─ managers/                  # 各獨立系統
└─ util/                      # Lore、文字與兼容工具
```

### 維護原則

1. 所有管理器只負責一個系統。
2. 配置讀取集中在 `ConfigManager`。
3. 玩家資料只由 `PlayerDataManager` 讀寫。
4. 物品識別不要使用 1.13+ API，使用 Lore、名稱和 ID。
5. 修改配置時先清空快取，再重新載入。
6. GUI 大小使用 9 的倍數，最大 54。
7. 所有玩家 UUID 資料都必須在退出和停服時保存。

## 配置文件

```text
plugins/LDAPI/config/
├─ general.yml       # 前綴、除錯、Lore key
├─ items.yml         # 自定義物品、材質、名稱、Lore
├─ attributes.yml    # 屬性 ID、顯示名稱、上下限
├─ jewelry.yml       # 飾品基礎屬性與每級成長
├─ spaces.yml        # 空間名稱、ID、大小
├─ commands.yml      # 指令文案和路徑
└─ tests.yml         # 自動/人工測試案例
```

玩家資料：

```text
plugins/LDAPI/playerdata/<UUID>.yml
```

## 詳細配置範例

### general.yml

```yaml
general:
  prefix: "&d[LDAPI] &r"
  debug: false
  command-prefix: ld
  lore:
    enabled: true
    ignore-color: true
    id-keys: [indierpg-id, item-id, mythic-id, namespace, jewelry-id]
```

### items.yml

```yaml
items:
  growth_core:
    id: growth_core
    namespace: ldapi:item
    material: EMERALD
    display-name: "&b成長核心"
    lore:
      - "&7item-id: growth_core"
      - "&7可提升飾品成長"
```

### attributes.yml

```yaml
attributes:
  attack:
    display-name: "&c攻擊力"
    default: 0
    min: 0
    max: 1000000
```

### jewelry.yml

```yaml
jewelry:
  enabled: true
  slots: 9
  definitions:
    abyss_ring:
      id: abyss_ring
      namespace: ldapi:jewelry
      name: "&5深淵戒指"
      material: DIAMOND
      base-attributes: {attack: 10, defense: 5}
      growth:
        max-level: -1
        sources: [online-time, real-time, special-item]
        per-level:
          "1": {attack: 1.0, defense: 0.5}
          "2": {attack: 1.5, defense: 0.8}
          "3": {attack: 2.5, defense: 1.2}
        default-per-level: {attack: 1.0, defense: 0.5}
```

### plugin.yml

主指令設定為：

```yaml
commands:
  ldapi:
    aliases: [ld]
```

因此 `/ld` 和 `/LD` 都可使用；`led` 不再註冊。

## 安裝與使用

1. 使用 Java 8 啟動 Paper 1.12.2。
2. 執行 `mvn clean package`。
3. 將 `target/LDAPI-1.0.0.jar` 放進 `plugins/`。
4. 啟動並停止伺服器一次，生成配置。
5. 編輯 `plugins/LDAPI/config/`。
6. 啟動伺服器後輸入 `/ld info`。
7. 配置修改後輸入 `/ld reload`。

## 指令

```text
/ld
/ld info
/ld reload
/ld give <物品ID>
/ld items
/ld gold
/ld rank
/ld bp
/ld admin reload
/ld admin setlevel <玩家> <飾品ID> <等級>
/ld admin addgrowth <玩家> <飾品ID> <數值>
/ld admin resetdata <玩家>
/sr、/ldsr
/talent、/ldtalent
/task、/ldtask
/crate、/ldcrate
```

## 編譯檢查

```bash
mvn clean package
```

若建置失敗，優先檢查：Java 是否為 8、Spigot API 是否可下載、所有 Manager 是否存在、`plugin.yml` 命令名稱是否和 `IndieRPG.java` 一致。
