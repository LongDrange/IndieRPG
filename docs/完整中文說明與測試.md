# IndieRPG 完整中文說明與測試

## 配置

插件會在 `plugins/IndieRPG/config/` 建立獨立配置：general、items、attributes、jewelry、spaces、commands、tests。玩家資料位於 `playerdata/<UUID>.yml`。

## Lore

物品可用 `indierpg-id`、`item-id`、`mythic-id`、`jewelry-id` 或 `namespace` 識別；比對會忽略顏色代碼與大小寫，兼容 MythicMobs 4.13.0 與 Minecraft 1.12.2。

## 飾品成長

`max-level: -1` 代表無限等級。`per-level` 可以為每個等級設定不同屬性，未指定的等級使用 `default-per-level`。上線時間每分鐘記錄一次；特殊成長物品可使用 `item-id: growth_core`。

## 測試

1. 啟動後確認 `config/` 與 `playerdata/` 建立。
2. 修改配置並使用 `/rpg reload`。
3. 測試彩色 Lore、中文 Lore、`mythic-id` 與 `jewelry-id`。
4. 修改第 1、2 級數值，確認每級增幅不同。
5. 退出再登入，確認玩家資料仍存在。

## 指令

`/rpg`、`/rpg info`、`/rpg reload`、`/rpg give <物品ID>`、`/rpg items`、`/rpg gold`、`/rpg rank`、`/rpg bp`、`/sr`、`/talent`、`/task`、`/crate`。
