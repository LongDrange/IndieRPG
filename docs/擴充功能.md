# 完整擴充說明

## 管理員指令

```text
/rpg admin reload
/rpg admin setlevel <玩家> <飾品ID> <等級>
/rpg admin addgrowth <玩家> <飾品ID> <數值>
/rpg admin resetdata <玩家>
```

## 成長來源

`jewelry.yml` 可使用 `online-time`、`real-time`、`special-item`。上線時間每分鐘累加；特殊物品使用 `item-id: growth_core` 識別；現實時間資料以秒保存，避免重新啟動後遺失。

## 注意

Minecraft 1.12.2 不支援新版 PersistentDataContainer，所以保留 Lore、名稱與 namespace 識別。核心 ID 使用英文，玩家顯示文字可使用繁體中文。
