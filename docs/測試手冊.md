# LDAPI 完整測試手冊

涵蓋所有系統的驗證流程。建議依序執行，每個測試通過再進行下一個。

---

## 測試環境

| 項目 | 版本 |
|---|---|
| 伺服器 | Paper 1.12.2 |
| Java | 8 |
| LDAPI | 1.0.0 |
| MythicMobs | 4.13.0（可選） |
| PlaceholderAPI | 最新（可選） |

---

## 前置準備

### 1. 部署插件

1. 把 `LDAPI-1.0.0.jar` 放入 `plugins/`
2. 啟動伺服器
3. 確認 Console 出現：

```
[LDAPI] 已載入 X 個職業
[LDAPI] 已載入 X 個副本定義
[LDAPI] 已載入 X 個寵物定義
[LDAPI] 已載入 X 個聲望陣營
[LDAPI] PlaceholderAPI 變數已註冊
[LDAPI] LDAPI 1.0.0 已啟用
```

### 2. 準備測試帳號

- 自己（OP）：`/op <你的名字>`
- 建議再開一個分身（可選）

### 3. 準備 MythicMobs 技能（若測試副本/寵物）

建立 `plugins/MythicMobs/Skills/LDAPI_Skills.yml`：

```yaml
Goblin:
  Type: ZOMBIE
  Display: '&a哥布林'
  Health: 50
  Damage: 5

GoblinArcher:
  Type: SKELETON
  Display: '&a哥布林弓手'
  Health: 30
  Damage: 3

GoblinChief:
  Type: ZOMBIE_VILLAGER
  Display: '&2哥布林酋長'
  Health: 500
  Damage: 15

PetBabyWolf:
  Type: WOLF
  Display: '&7小狼'
  Health: 20
```

執行 `/mm reload`。

## 測試 1：屬性引擎

**目標：** 確認基礎屬性正確載入。

### 步驟

1. 執行 `/ld info`
2. 或使用 PlaceholderAPI：
   ```
   /papi parse me %ldapi_health%
   ```
3. 預期：`20`（`attributes.yml` 的 `health.default`）

### 進階測試

新增一個屬性：

1. 編輯 `config/attributes.yml`，加入：

```yaml
  test-stat:
    display-name: "&d測試屬性"
    default: 100
    min: 0
    max: 9999
```

2. `/ld reload`
3. `/papi parse me %ldapi_attack%` 應該正常
4. 要讀 `test-stat` 需要自訂 Placeholder（目前沒有內建）

## 測試 2：職業系統

**目標：** 確認選職業、升級、屬性加成。

### 步驟

1. 執行 `/job` → 應開啟職業選擇 GUI
2. 點擊「戰士」（或執行 `/job warrior`）
3. 預期：聊天欄出現 `職業已設定為 §c戰士`
4. `/job` → 顯示：

```
職業：§c戰士  等級 1  經驗 0/100
```

5. 打怪 20 次（殺殭屍即可）
6. 每次殺怪後職業經驗 +5
7. 累積 100 經驗 → 升級到 2 級
8. 預期：聊天欄出現 `§e[職業] §7等級提升至 §f2`

### 驗證屬性加成

1. 選戰士前：`/papi parse me %ldapi_attack%` → `0`
2. 選戰士並升到 2 級：
   - 戰士 `attack: 2.0` 每級
   - 2 級 = `2.0 * 2 = 4`
3. `/papi parse me %ldapi_attack%` → `4`

### 測試換職業

1. 執行 `/job mage`
2. 因為 `allow-change: true`，應成功切換
3. 若要禁止，把 `jobs.yml` 的 `allow-change` 改成 `false`，重載後測試

## 測試 3：天賦系統

**目標：** 確認天賦 GUI、加點、屬性生效。

### 準備天賦點

執行：

```
/ld admin addgrowth <你的名字> attack 10
```

或直接編輯 `plugins/LDAPI/playerdata/<你的UUID>.yml`：

```yaml
talent-points: 10
```

### 步驟

1. 執行 `/talent` → 開啟天賦 GUI
2. GUI 中應該看到 5 個圖示：Attack、Defense、Health、Crit、Lifesteal
3. 點擊「Attack」圖示
4. 預期：
   - 聊天欄 `已升級天賦：§c&lAttack (1/20)`
   - 天賦點 -1
   - GUI 自動刷新，顯示 `1/20`
5. 反覆點擊，直到達到 20 級（滿級）
6. 預期：滿級後顯示 `該天賦已滿級`

### 驗證屬性生效

1. 加點前：`/papi parse me %ldapi_attack%` → `0`
2. Attack 天賦加到 10 級（每級 +0.5）：
3. `/papi parse me %ldapi_attack%` → `5`

### 測試重置

1. GUI 中點擊 TNT 圖示（`reset-slot: 40`）
2. 預期：退還 80% 天賦點
3. 天賦等級歸零

## 測試 4：戰鬥系統

**目標：** 確認攻擊力、爆擊、防禦減傷。

### 測試攻擊加成

1. 選戰士，升到 10 級（attack +20）
2. 空手打殭屍
3. 觀察傷害：原本空手約 1，現在應該約 21

### 測試爆擊

1. 天賦「Crit」加到 5 級（`crit-chance: 0.02 * 5 = 0.10 = 10%`）
2. 打怪 20 次
3. 預期：約 2 次出現 `§e爆擊！` 訊息
4. 爆擊時傷害應該 ×1.5（預設 `crit-damage: 0.5`）

### 測試防禦減傷

1. 選戰士，升到 10 級（defense +15）
2. 被殭屍打
3. 減傷公式：`reduction = defense / (defense + 100) = 15/115 ≈ 13%`
4. 原本傷害 3 → 現在約 2.6

### 測試職業經驗

1. 記錄當前職業經驗（`/job` 查看）
2. 打 10 隻怪
3. 預期：經驗 +50

## 測試 5：隊伍系統

**目標：** 確認邀請、接受、經驗共享。

**需要兩個玩家**（可開分身或用測試帳號）。

### 步驟

1. 玩家 A：`/party create`
   - 預期：`隊伍已建立。`
2. 玩家 A：`/party invite <玩家B>`
   - 玩家 A 看到：`已邀請 <玩家B>`
   - 玩家 B 看到：`<玩家A> 邀請你加入隊伍，輸入 /party accept 接受`
3. 玩家 B：`/party accept`
   - 兩人看到：`<玩家B> 加入了隊伍`
4. 玩家 A 打怪
5. 玩家 B 站在 30 格內
6. 玩家 B 應該獲得職業經驗（共享倍率 0.6 → 3 經驗）

### 測試離開

1. 玩家 B：`/party leave`
2. 預期：`<玩家B> 離開了隊伍`
3. 玩家 A 應看到通知

### 測試隊長轉移

1. A、B 同隊
2. A 執行 `/party leave`
3. 預期：B 成為新隊長

## 測試 6：公會系統

**目標：** 確認建立、成員、Buff、等級。

### 準備金幣

執行：

```
/ld admin addgrowth <你的名字> attack 0
```

或直接編輯 playerdata 給金幣：

```yaml
gold: 10000
```

### 步驟

1. `/guild create 測試公會`
2. 預期：`公會建立成功：測試公會`，金幣 -5000
3. `/guild` → 開啟公會資訊 GUI
4. 應該看到：
   - 書本圖示：公會名稱、等級 1、經驗 0、成員 1
   - 玩家頭顱：顯示自己的名字與職位 `LEADER`

### 測試公會 Buff

1. 編輯 `config/guilds.yml`，加：

```yaml
buffs:
  "2":
    attack: 5.0
```

2. `/ld reload`
3. 讓公會升到 2 級（打怪 +2 經驗 / 隻，升 2 級需 10000 經驗 → 約 5000 隻）
4. 或直接改 playerdata 的 `guild-level: 2`（在 `guilds.yml` 手動設定，或暫時降低門檻）
5. 預期：玩家攻擊力 +5

### 測試邀請

1. 玩家 A（會長）：`/guild invite <玩家B>`
2. 玩家 B：`/guild accept`
3. 兩人 `/guild` 應該看到成員 2 人

## 測試 7：副本系統

**目標：** 確認傳送、波次、獎勵。

### 準備模板世界

1. 建立新世界 `dungeon_goblin`，設好地形
2. 關服
3. 搬到 `plugins/LDAPI/dungeon-templates/dungeon_goblin/`
4. 從 `server.properties` 移除自動載入
5. 重啟

### 測試進入

1. 確保職業等級 ≥ 5（`dungeons.yml` 的 `min-level: 5`）
2. 執行 `/dungeon list`
3. 預期：

```
 - goblin_cave
 - abyss_temple
```

4. 執行 `/dungeon enter goblin_cave`
5. 預期：
   - 傳送到副本世界
   - 聊天欄 `§a已進入副本：§a哥布林洞穴`
   - 幾秒後出現 `§6[副本] §e第 1 波來襲！`

### 測試波次

1. 殺光第 1 波的怪
2. 等 2-4 秒
3. 預期：`§6[副本] §e第 2 波來襲！`
4. 繼續殺到最後一波

### 測試獎勵

1. 全清後
2. 預期：
   - `§6[副本] §e所有波次已清除！`
   - `§6[副本] §a完成！§7+ 5000 金幣`
   - 金幣 +5000
   - 獲得 `growth_core` 物品
   - 戰令經驗 +200

### 測試離開

1. `/dungeon leave`
2. 預期：傳回主世界，副本世界被刪除
3. 冷卻中執行 `/dungeon enter goblin_cave`
4. 預期：`§c冷卻中，剩餘 X 秒。`

### 測試找不到模板

1. 刪除 `dungeon-templates/dungeon_goblin`
2. `/dungeon enter goblin_cave`
3. 預期：`§c找不到模板世界：dungeon_goblin`

## 測試 18：邊界情況

### 未選職業的玩家

1. 新玩家未選職業
2. 打怪 → 不會加職業經驗（`data.job` 為空）
3. 被打 → 無防禦減傷

### 天賦點為 0

1. 天賦點 = 0
2. `/talent` → 點擊升級
3. 預期：`天賦點不足（需要 1 點）`

### 公會金幣不足

1. 金幣 < 5000
2. `/guild create 測試`
3. 預期：`需要 5000 金幣`

### 隊伍滿員

1. `max-members: 6`，組滿 6 人
2. 再 `/party invite` 第 7 人
3. 預期：`隊伍已滿。`

### 副本冷卻中

1. 完成副本後立即重進
2. 預期：`冷卻中，剩餘 X 秒。`

### 找不到玩家

1. `/party invite NotARealPlayer`
2. 預期：靜默失敗或提示（依實作，目前不提示）

## 常見錯誤排查

### 錯誤 1：`ClassNotFoundException: io.lumine.xikage...`

MythicMobs 沒裝或版本不對。解法：

- 裝 MythicMobs 4.13.0
- 或在 `mythicmobs.yml` 設 `enabled: false`

### 錯誤 2：`NullPointerException at AttributeEngine.recalculate`

`plugin.getJobManager()` 可能為 null。解法：

- 確認 `IndieRPG.onEnable()` 中 `jobManager = new JobManager(this)` 在 `attributeEngine = new AttributeEngine(this)` **之前**

### 錯誤 3：玩家屬性沒更新

- 檢查 `/ld reload` 是否成功
- 玩家重登一次
- 或執行 `/ld admin addgrowth <玩家> attack 0` 觸發重算

### 錯誤 4：中文亂碼

所有 `.java` 和 `.yml` 都要存成 UTF-8。用 VS Code 右下角確認。

### 錯誤 5：副本世界無法刪除

Windows 檔案鎖。解法：

- 確認沒玩家在副本
- 等幾秒再試
- 手動刪除 `server/dungeon_goblin_inst_*/`
