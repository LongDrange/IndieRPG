## 配置使用方法

### 1. general.yml

```yaml
general:
  prefix: "&d[LDAPI] &r"
  debug: false
  command-prefix: ld
  lore:
    enabled: true
    ignore-color: true
    id-keys: [indierpg-id, item-id, mythic-id, namespace]
```

這份文件決定前綴、除錯與物品識別方式。

### 2. items.yml

```yaml
items:
  growth_core:
    id: growth_core
    namespace: ldapi:item
    material: EMERALD
    display-name: "&b成長核心"
    lore:
      - "&7item-id: growth_core"
```

新增物品時，需保持 `id` 與 `material` 正確。然後可以用：

```text
/ld give growth_core
```

### 3. attributes.yml

```yaml
attributes:
  attack:
    display-name: "&c攻擊"
    default: 0
    min: 0
    max: 1000000
```

這裡用於定義屬性。

### 4. jewelry.yml

```yaml
jewelry:
  enabled: true
  slots: 9
  definitions:
    abyss_ring:
      id: abyss_ring
      namespace: ldapi:jewelry
      name: "&5深淵戒指"
      material: DIAMOND
```

這裡是飾品系統的核心配置，記得設定好：
- id
- name
- material
- base-attributes
- growth

### 5. shop.yml

```yaml
shop:
  enabled: true
  items:
    growth_core:
      price: 80
      material: EMERALD
      display-name: "&b成長核心"
      item: growth_core
```

設定商店商品後，玩家可透過商店系統購買對應道具。

### 6. dailyreward.yml

```yaml
dailyreward:
  enabled: true
  gold: 100
  xp: 25
  cooldown-hours: 24
```

此設定用於每日簽到系統。

## 進階使用教學

### 1. 自定義物品設計

新增一個新物品步驟：

1. 在 `items.yml` 中加入新的 `id`
2. 設定 `material`
3. 設定 `display-name`
4. 設定 `lore`
5. 重新載入：

```text
/ld reload
```

6. 測試：

```text
/ld give 新物品ID
```

### 2. 飾品成長設計

在 `jewelry.yml` 中設定：

```yaml
growth:
  max-level: -1
  sources: [online-time, real-time, special-item]
  per-level:
    "1": {attack: 1.0, defense: 0.5}
```

代表：
- 無限制等級
- 可依在線時間、現實時間、特殊物品增加成長
- 每一級都能設定不同增幅

### 3. 管理員調試

管理員可直接執行：

```text
/ld admin setlevel 玩家 abyss_ring 10
/ld admin addgrowth 玩家 abyss_ring 25
/ld admin resetdata 玩家
```

這讓伺服器管理員能直接測試玩家設定。

### 4. 商店與每日獎勵

設定完 `shop.yml` 與 `dailyreward.yml` 後，玩家即可：
- 透過商店購買道具
- 每日簽到領取獎勵

## 最終發佈建議

- 伺服器環境請使用 Paper 1.12.2 + Java 8
- 每次修改 YAML 後請執行 `/ld reload`
- 升級版本前先備份 `plugins/LDAPI/`
- 若有 MythicMobs，請安裝 4.13.0 版本

## 總結

LDAPI 的基本使用方式非常簡單：

1. 丟入插件
2. 啟動伺服器
3. 編輯配置
4. 使用 `/ld reload`
5. 透過 `/ld give` / `/sr` / `/task` / `/crate` 進行測試

這份文件已經整合了詳細使用教學，方便使用者快速上手與維護。
