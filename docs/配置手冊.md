## config.yml

主配置，包含各系統的開關與核心參數。

### general

```yaml
general:
  prefix: "&d[IndieRPG] &r"    # 訊息前綴，支援 & 顏色代碼
  debug: false                  # 是否輸出除錯訊息
```

| 欄位 | 型別 | 預設 | 說明 |
|---|---|---|---|
| `prefix` | String | `&d[IndieRPG] &r` | 所有訊息的統一前綴 |
| `debug` | Boolean | `false` | 開啟後 Console 會輸出詳細流程 |

### battlepass（戰令）

```yaml
battlepass:
  enabled: true
  xp-per-level: 100
  max-level: 100
  kill-xp: 5
  milestone-every: 10
  milestone-rewards: {talent-points: 5, gold: 500}
  gold-per-level: 10
```

| 欄位 | 說明 |
|---|---|
| `xp-per-level` | 升一級所需經驗 |
| `max-level` | 等級上限 |
| `kill-xp` | 每殺一隻怪的經驗 |
| `milestone-every` | 每幾級給里程碑獎勵 |
| `milestone-rewards` | 里程碑獎勵內容 |
| `gold-per-level` | 每升一級給的金幣 |

### economy（經濟）

```yaml
economy:
  enabled: true
  starting-gold: 0
```

| 欄位 | 說明 |
|---|---|
| `starting-gold` | 新玩家初始金幣 |

### talent（天賦）

```yaml
talent:
  enabled: true
  menu-title: "&d&lTalent System &7[Points: {points}]"
  gui-size: 45
  reset-slot: 40
  reset-refund-percent: 80
  trees:
    attack:
      display-name: "&c&lAttack"
      icon: DIAMOND_SWORD
      max-level: 20
      points-per-level: 1
      slot: 11
      lore:
        - "&7每級：&c+0.5 攻擊力"
        - "&7當前：&f{level}/{max}"
      attributes-per-level:
        attack: 0.5
```

| 欄位 | 說明 |
|---|---|
| `menu-title` | GUI 標題，`{points}` 會替換為當前點數 |
| `gui-size` | GUI 格數（必須是 9 的倍數） |
| `reset-slot` | 重置按鈕的格子位置 |
| `reset-refund-percent` | 重置時退還的百分比 |
| `trees.<id>.slot` | 該天賦在 GUI 中的格子 |
| `attributes-per-level` | 每級增加的屬性 |

**可用的屬性 key：**

- `attack` 攻擊力
- `defense` 防禦力
- `health` 生命值
- `crit-chance` 爆擊率（0.02 = 2%）
- `crit-damage` 爆擊傷害倍率（0.5 = +50%）
- `move-speed` 移動速度
- `lifesteal` 吸血

### task（任務）

```yaml
task:
  enabled: true
  required-kills: 15
  rewards: {gold: 150, talent-points: 5, battlepass-xp: 50}
```

### crate（寶箱）

```yaml
crate:
  enabled: true
  trigger-items:
    common: ["&7Common Crate"]
    rare: ["&9Rare Crate"]
  rewards:
    common:
      - {chance: 0.60, gold: 10, talent-points: 0, battlepass-xp: 5}
      - {chance: 0.30, gold: 50, talent-points: 0, battlepass-xp: 10}
      - {chance: 0.10, gold: 100, talent-points: 1, battlepass-xp: 20}
```

| 欄位 | 說明 |
|---|---|
| `trigger-items` | 各階寶箱的辨識名稱（右鍵觸發） |
| `chance` | 每個獎勵的機率，加總應為 1.0 |

### rank（稱號）

```yaml
rank:
  enabled: true
  items:
    "Warrior Title": warrior
    "Knight Title": knight
  ranks:
    default: {display: "&7&l[Rookie]", chat-prefix: "&7[Rookie] "}
    warrior: {display: "&c&l[Warrior]", chat-prefix: "&c[Warrior] "}
```

## config/general.yml

```yaml
general:
  prefix: "&d[LDAPI] &r"
  debug: false
  command-prefix: ld
  lore:
    enabled: true
    ignore-color: true
    id-keys: [indierpg-id, item-id, mythic-id, namespace, jewelry-id, card-id, soul-bead-id]
```

| 欄位 | 說明 |
|---|---|
| `command-prefix` | 主指令名稱 |
| `lore.id-keys` | 識別物品時會讀取的 Lore key 清單 |

**Lore ID 範例：**

```yaml
lore:
  - "&7item-id: growth_core"
  - "&7jewelry-id: abyss_ring"
```

系統會自動解析這些行，提取 `growth_core`、`abyss_ring`。

## config/attributes.yml

定義所有可用的屬性。

```yaml
attributes:
  attack:
    display-name: "&c攻擊力"
    default: 0
    min: 0
    max: 1000000
  health:
    display-name: "&a生命值"
    default: 20
    min: 1
    max: 1000000
  crit-chance:
    display-name: "&e爆擊率"
    default: 0.05
    min: 0
    max: 1
```

| 欄位 | 說明 |
|---|---|
| `display-name` | GUI 顯示名稱 |
| `default` | 基礎值（每個玩家都有） |
| `min` / `max` | 數值上下限 |

**新增自訂屬性：**

1. 在 `attributes.yml` 加新 key
2. 在 `jobs.yml` 或天賦的 `attributes-per-level` 中引用
3. 重載 (`/ld reload`)

## config/jobs.yml

```yaml
allow-change: true    # 是否允許玩家換職業

jobs:
  warrior:
    display-name: "&c戰士"
    max-level: 100
    exp-formula:
      base: 100      # 升級經驗 = base * level^power
      power: 2.0
    attributes-per-level:
      attack: 2.0
      defense: 1.5
      health: 8.0
    skills:
      "10": "WarriorSlash"
      "30": "WarriorWhirlwind"
```

| 欄位 | 說明 |
|---|---|
| `allow-change` | `false` 表示選定後不能改 |
| `exp-formula.base` | 經驗公式基底 |
| `exp-formula.power` | 經驗公式次方 |
| `attributes-per-level` | 每級屬性加成 |
| `skills` | 幾級解鎖什麼技能（MythicMobs 技能 ID） |

**經驗公式範例：**

- `base=100, power=2.0`：從 1 級升 2 級需要 `100 * 1^2 = 100`；10 級升 11 級需要 `100 * 10^2 = 10000`
- `base=50, power=1.5`：較平緩的成長曲線

## config/dungeons.yml

```yaml
dungeons:
  goblin_cave:
    name: "&a哥布林洞穴"
    template-world: "dungeon_goblin"
    min-level: 5
    max-players: 4
    time-limit: 1800
    cooldown: 3600
    waves:
      - mobs: ["Goblin", "Goblin", "GoblinArcher"]
      - mobs: ["GoblinChief"]
    rewards:
      gold: 5000
      battle-pass-exp: 200
      item: "growth_core"
```

| 欄位 | 說明 |
|---|---|
| `template-world` | 模板世界名稱（放在 `dungeon-templates/`） |
| `min-level` | 進入最低職業等級 |
| `time-limit` | 時間限制（秒），`0` 表示無限 |
| `cooldown` | 冷卻時間（秒） |
| `waves` | 波次清單，每波是一組怪物 ID（MythicMobs internal name） |
| `rewards` | 全清後獎勵 |

**模板世界準備：**

1. 建立新世界 `dungeon_goblin`
2. 關服
3. 搬到 `plugins/LDAPI/dungeon-templates/dungeon_goblin/`
4. 從 `server.properties` 移除自動載入

## config/pets.yml

```yaml
pets:
  baby_wolf:
    name: "&7小狼"
    mythic-id: "PetBabyWolf"
    max-level: 50
    bonus-per-level:
      attack: 0.5
      move-speed: 0.001
```

| 欄位 | 說明 |
|---|---|
| `mythic-id` | MythicMobs 中定義的怪物 ID |
| `bonus-per-level` | 每級屬性加成 |

需要在 MythicMobs 有對應的怪物定義：

```yaml
PetBabyWolf:
  Type: WOLF
  Display: '&7小狼'
  Health: 20
```

## config/mythicmobs.yml

```yaml
mythicmobs:
  enabled: true
  api-version: "4.13.0"
  events:
    mythic_zombie:
      death:
        chance: 0.25
        gold: 25
        battlepass-xp: 10
        item: growth_core
        command: ""
```

| 欄位 | 說明 |
|---|---|
| `enabled` | 是否啟用 MM 整合 |
| `api-version` | 對應的 MM 版本 |
| `events.<mob-id>.death.chance` | 觸發機率 |
| `death.gold` / `death.battlepass-xp` | 獎勵 |
| `death.command` | 執行指令，`{player}` 會被替換 |

## 熱重載

修改任何 YAML 後，執行：

```
/ld reload
```

或從 Console：

```
ld reload
```

重載範圍：

| 檔案 | 是否熱重載 |
|---|---|
| config.yml | ✅ |
| config/*.yml | ✅ |
| playerdata/*.yml | ❌（玩家資料，需重登） |
| MythicMobs 定義 | ❌（需 `/mm reload`） |

## 常見配置問題

### Q1：屬性沒生效

檢查：
1. `attributes.yml` 的 key 是否拼對（大小寫不重要）
2. `jobs.yml` 的 `attributes-per-level` 是否引用了正確 key
3. 玩家是否選了職業（`/job`）
4. 是否執行了 `/ld reload`

### Q2：MythicMobs 技能沒觸發

檢查：
1. `config/mythicmobs.yml` 的 `enabled: true`
2. MythicMobs 版本是 4.13.0
3. MM 中有對應的技能定義
4. `/mm reload` 重載 MM

### Q3：副本傳送失敗

常見原因：
- `dungeon-templates/<name>` 不存在
- 模板世界被伺服器自動載入（要在 `server.properties` 移除）
- 玩家職業等級不足

### Q4：寵物召喚失敗

- MythicMobs 中沒有對應的 `mythic-id`
- MythicMobs 沒載入
