# 詳細配置範例

所有檔案放在 `plugins/LDAPI/config/`。以下範例以繁體中文顯示，但 ID、材質、權限使用英文，避免兼容問題。

## 1. general.yml

```yaml
general:
  # 所有 LDAPI 訊息前綴。& 是 Minecraft 顏色符號。
  prefix: "&d[LDAPI] &r"
  # true 會輸出更多除錯訊息；正式伺服器建議 false。
  debug: false
  # 文件與提示使用的主命令前綴。
  command-prefix: ld
  lore:
    # 是否啟用 Lore 識別。
    enabled: true
    # 比對 ID 時忽略顏色代碼。
    ignore-color: true
    # 只要 Lore 出現以下 key，就可作為物品身份識別。
    id-keys:
      - indierpg-id
      - item-id
      - mythic-id
      - namespace
      - jewelry-id
      - card-id
      - soul-bead-id
```

Lore 範例：`&7item-id: growth_core`。

## 2. items.yml

```yaml
items:
  # 區塊名稱通常等於物品 ID。
  growth_core:
    id: growth_core
    # 自訂 namespace，供文件與外部插件辨識。
    namespace: ldapi:item
    # 必須是 1.12.2 存在的 Bukkit Material。
    material: EMERALD
    display-name: "&b成長核心"
    lore:
      - "&7item-id: growth_core"
      - "&7namespace: ldapi:item"
      - "&7右鍵可作為飾品成長素材"
    amount: 1

  abyss_ring:
    id: abyss_ring
    namespace: ldapi:jewelry
    material: DIAMOND
    display-name: "&5深淵戒指"
    lore:
      - "&7jewelry-id: abyss_ring"
      - "&7namespace: ldapi:jewelry"
```

完成後使用 `/ld reload`，再使用 `/ld give growth_core` 測試。`material` 寫錯會使物品無法建立。

## 3. attributes.yml

```yaml
attributes:
  attack:
    display-name: "&c攻擊力"
    default: 0
    min: 0
    max: 1000000
  defense:
    display-name: "&9防禦力"
    default: 0
    min: 0
    max: 1000000
  health:
    display-name: "&a生命值"
    default: 20
    min: 0
    max: 1000000
```

`default` 是初始值；`min` / `max` 限制管理器可以接受的數值。屬性 ID 必須和飾品、天賦設定中的 key 相同。

## 4. jewelry.yml

```yaml
jewelry:
  enabled: true
  # GUI 槽位必須是 9 的倍數，1.12.2 最大通常為 54。
  slots: 9
  definitions:
    abyss_ring:
      id: abyss_ring
      namespace: ldapi:jewelry
      name: "&5深淵戒指"
      material: DIAMOND
      base-attributes:
        attack: 10
        defense: 5
      growth:
        # -1 代表不限制等級；改成 50 即最高 50 級。
        max-level: -1
        # 可被成長管理器使用的來源名稱。
        sources: [online-time, real-time, special-item]
        per-level:
          "1": {attack: 1.0, defense: 0.5}
          "2": {attack: 1.5, defense: 0.8}
          "3": {attack: 2.5, defense: 1.2}
        # 沒有明確列出的等級使用這組數值。
        default-per-level: {attack: 1.0, defense: 0.5}
```

使用 `/ld admin setlevel 玩家 abyss_ring 10` 可測試等級，使用 `/ld admin addgrowth 玩家 abyss_ring 25` 可測試成長值。

## 5. spaces.yml

```yaml
spaces:
  enabled: true
  default-space: basic
  definitions:
    basic:
      id: basic
      display-name: "&a基礎空間"
      # 1.12.2 GUI 以 9 的倍數表示容量。
      size: 27
      permission: ""
    advanced:
      id: advanced
      display-name: "&9進階空間"
      size: 54
      permission: ldapi.space.advanced
  trigger-items:
    - "item-id: space_ring_basic"
    - "item-id: space_ring_advanced"
```

權限為空字串代表所有玩家可用。玩家也可以使用 `/sr` 開啟介面。

## 6. commands.yml

```yaml
commands:
  main: ld
  aliases: [ld]
  messages:
    no-permission: "&c你沒有權限。"
    reload-success: "&aLDAPI 配置已重新載入。"
    unknown-item: "&c找不到物品：{id}"
    unknown-command: "&c未知指令，輸入 /ld 查看幫助。"
```

這裡主要保存命令顯示文字；真正的 Bukkit 註冊仍由 `plugin.yml` 控制。

## 7. tests.yml

```yaml
tests:
  # 啟動時檢查配置檔是否存在。
  enabled: true
  required-files:
    - general.yml
    - items.yml
    - attributes.yml
    - jewelry.yml
    - spaces.yml
    - commands.yml
    - shop.yml
    - dailyreward.yml
    - mythicmobs.yml
  # 測試時可以在控制台輸出檢查結果。
  verbose: false
```

## 8. shop.yml

```yaml
shop:
  enabled: true
  menu-title: "&6&lLDAPI 商店 &7[金幣：{gold}]"
  # key 是商品在配置中的唯一 ID。
  items:
    growth_core:
      price: 80
      material: EMERALD
      display-name: "&b成長核心"
      # 必須對應 items.yml 的物品 ID。
      item: growth_core
      slot: 11
    abyss_ring:
      price: 300
      material: DIAMOND
      display-name: "&5深淵戒指"
      item: abyss_ring
      slot: 15
```

價格不可為負數。購買前確認對應 `item` 存在。

## 9. dailyreward.yml

```yaml
dailyreward:
  enabled: true
  # 兩次領取至少相隔 24 小時。
  cooldown-hours: 24
  message: "&e[每日獎勵] &7第 {day} 天：+{gold} 金幣，+{xp} XP"
  rewards:
    day1: {gold: 100, xp: 25, item: growth_core}
    day2: {gold: 150, xp: 30, item: ""}
    day3: {gold: 200, xp: 50, item: growth_core}
    day7: {gold: 1000, xp: 200, item: abyss_ring}
```

`item` 為空字串代表只給金幣與 XP。每日資料會保存到玩家 UUID 檔案。

## 10. mythicmobs.yml

```yaml
mythicmobs:
  # false 時完全不處理 MythicMobs 事件。
  enabled: true
  api-version: "4.13.0"
  events:
    ldapi_boss:
      # 此 key 必須是 MythicMobs 怪物 internal name。
      spawn:
        skill: LDAPI_BOSS_SPAWN
      death:
        # 0.0 到 1.0；1.0 必定發獎，0.25 是 25%。
        chance: 1.0
        skill: LDAPI_BOSS_DEATH
        gold: 500
        battlepass-xp: 50
        # 對應 items.yml。
        item: growth_core
        # 空字串表示不執行命令。
        command: ""
    mythic_zombie:
      death:
        chance: 0.25
        gold: 25
        battlepass-xp: 10
        item: growth_core
```

MythicMobs 技能檔範例：

```yaml
LDAPI_BOSS_DEATH:
  Skills:
  - message{m="&6Boss 已被擊敗！"} @PlayersInRadius{r=20}
```

完成後使用 MythicMobs 自己的 reload，再讓玩家擊殺怪物測試。
